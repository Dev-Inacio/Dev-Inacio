## 📐 Boas práticas que aplico
 
- Arquitetura em camadas: **controller → service → repository**
- **DTOs** separados das entidades
- Injeção de dependência por construtor
- Validação de entrada com **Bean Validation**
- Tratamento global de exceções com `@RestControllerAdvice` e respostas HTTP padronizadas
- Restrições no banco (`UNIQUE`, `NOT NULL`) e uso de `@Enumerated`
- Senhas com hash **BCrypt** e autenticação com **JWT**
- Segredos em variáveis de ambiente, fora do repositório
- Commits seguindo **Conventional Commits**

## 🚀 Projetos
 
### [zBox](https://github.com/Dev-Inacio/zbox-app) · *em desenvolvimento*
Sistema de gestão com módulos de clientes, orçamentos, pedidos e financeiro.
- API REST em **Java + Spring Boot**
- Autenticação e autorização com **Spring Security + JWT** e controle de acesso por perfil
- Tratamento global de exceções e contratos de API documentados
- Frontend em **React + TypeScript**
### [Pedidos App](https://github.com/Dev-Inacio/pedidos-app)
Sistema de pedidos em **Java** com persistência em **MySQL** via JDBC.
- Cadastro de clientes e produtos, controle de estoque e status de pedidos
- Padrão DAO com camada de serviço separada
- Exceções de negócio personalizadas e controle de transações
- Configuração do banco fora do código-fonte
### [Gestão Financeira](https://github.com/Dev-Inacio/gestao-financeira-java)
Aplicação em **Java** com **MySQL** para controle de usuários, contas e transações (receitas e despesas).
- Organização em camadas (model, repository, service)
- Validação de dados e exceções personalizadas
### [Testes E2E com Playwright](https://github.com/Dev-Inacio/playwright-e2e-saucedemo)
Suíte de testes end-to-end com **Playwright + TypeScript**, usando Page Object Model e pipeline de CI no **GitHub Actions**.
